# Image credits — capture record

Fill one block per image. Every field is required unless marked optional.
Commons licences are per-file: check each file page individually.

Licence preference: CC0 / public domain first, then CC-BY / CC-BY-SA.
Do NOT use CC-BY-NC or CC-BY-ND.

Sensitive-data rule (applies to imagery):
- No wild California puma photo tied to a real location. Prefer captive / zoo /
  out-of-region animals.
- Strip EXIF on every file before it goes in the repo.
- Do not caption a precise wild-sighting location.

Target pages and how many to source:
- puma.qmd       — 1 puma (Puma concolor)
- bobcat.qmd     — 1 bobcat (Lynx rufus)
- index.qmd      — 2 puma and bobcat
- landscape.qmd  — 1 open-space / protected-land photo
